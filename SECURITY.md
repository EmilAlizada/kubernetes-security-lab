# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for a suspected security vulnerability.

Report concerns privately to:

**alizadaemil404@gmail.com**

Include:

- affected manifest or control
- security impact
- reproduction steps
- suggested mitigation, if known

## Scope

The following are in scope:

- Kubernetes manifest security
- workload privilege configuration
- NetworkPolicy behavior
- resource controls
- CI security-policy tests

This repository is a portfolio / learning lab, not a public production cluster.

Do not test infrastructure or Kubernetes environments that you do not own or have explicit authorization to assess.
